# v0.3 驗收界線

| 項目 | 實作與驗證 | 還需要什麼 |
|---|---|---|
| 空白啟動、五工作區 | 已保留，既有專案可恢復 | 公開與本機來源的資料需自行匯入搬移 |
| 本機模型 | Ollama 真實呼叫與來源紀錄、失敗保留 | 模型品質需獨立評估，不是雲端共用 AI |
| 首頁與發現理由 | 四項摘要、候選優先、資料→條件／模型理由、下一步 | 優先性需人工評分，模型可能只指出資料缺口 |
| 自動搜尋 | Crossref 真實查詢；支持與反證分別搜尋 | 完整政府開放資料搜尋未接通 |
| 文件抽取 | PDF／文字讀取、AI 摘要草稿、原文比對、人工確認 | 分批長文件與掃描 PDF OCR 未實作 |
| 證據品質 | 來源、時間、分母、原文、缺漏、獨立性說明；重複與矛盾提示 | 仍非自動真偽判決 |
| 成因 | AI 生成、支持／反證、比較、異議重查 | 候選不等於真正原因；搜尋命中需核對 |
| 方案 | 對應假說與提出理由、未知數值留空、維持現況基準 | AI 一般問題尚無經驗證的效果模型 |
| 評分 | 新紀錄統一 0–4，舊 0–5 原樣顯示且保留歷史 | 需獨立人工評分與規準校準 |
| A/B/C | 可以實際逐組呼叫模型，保存失敗與凍結輸入 | 正式多案例實驗與評分尚未完成 |
| 報告 | 原有研究報告加上模型與搜尋處理範圍 | 不自動宣稱優越性或政策成效 |

所有測試用合成文字、測試分數與實跑輸出均留在本機 outputs，不會當成公開預載研究結果。
