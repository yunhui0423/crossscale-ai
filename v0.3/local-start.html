在你的電腦啟動 CrossScale AI

如果顯示「127.0.0.1 拒絕連線」，請先在目前這台 Windows 電腦下載並啟動服務。工具端曾成功連線，不能代表你的電腦已啟動。

下載 Windows 本機啟動包

  1. 下載 ZIP 後，按「全部解壓縮」。
  2. 雙擊解壓資料夾中的 Start-CrossScale.cmd。
  3. 看到黑色視窗顯示 READY 後，Edge 會開啟本機網站。使用期間請保持黑色視窗開啟。

需要 Node.js 與 Ollama。啟動器會列出缺少項目，不會自動安裝或變更安全設定。

如果失敗，請傳黑色視窗裡 STARTUP FAILED 後的文字。這樣才能確認你自己的電腦是哪一段沒有啟動。
