# CrossScale AI v0.3｜本機 Ollama 研究原型

保留探索總覽、證據資料庫、可能成因推理、方案實驗室、研究評估五個工作區。首次開啟不設定案件，不預載研究結果。公開版與本機版的研究資料保存在各自瀏覽器來源，請用「匯出／匯入研究專案」搬移；兩者不會自動同步。

## 開啟與連線

1. 需要 Node.js（支援內建 fetch 的版本，建議 22 以上）、Ollama。PDF 文字解析另需 Python 與 `pypdf`；掃描 PDF 須先 OCR。
2. 在這個資料夾執行 `./啟動本機研究服務.ps1`。它只在 `127.0.0.1:8787` 啟動服務，不對外網開放，不建立付費雲端帳號。
3. 開啟 `http://127.0.0.1:8787`，點「本機 AI 連線」。預設 `qwen3:0.6b`，可改成 `ollama list` 中現有的模型。缺少時可執行 `ollama pull qwen3:0.6b`。
4. 公開網站也能連本機服務，但瀏覽器可能要求允許本機網路存取；無法連線時使用本機網站。其他訪客不能使用你的模型，必須啟動自己的服務。
5. 停止時執行 `./停止本機研究服務.ps1`；它只停止 CrossScale 服務，保留 Ollama。

公開原始碼下載解壓後，進入 `v0.3` 資料夾啟動。交付 ZIP 則直接在解壓後的主資料夾啟動。服務同時支援這兩種目錄排列。

## 研究流程

建立案件（主題、地區、期間、領域）→ 資料庫搜尋或讀取文件 → 人工確認證據 → 首頁「AI 發現問題」→ 查看支持、反證、替代解釋與候選成因 → 比較方案與維持現況 → 匯出完整研究報告。

- **來源搜尋**：目前實作 Crossref 學術文獻詮釋資料檢索，不是完整政府資料或全網搜尋。搜尋結果不直接當證據。政府資料保留官方搜尋入口，取得網址後可讀取來源。全文可能因授權或網站限制讀取失敗，系統會明示。
- **讀取與抽取**：支援公開 HTTPS 文字／HTML／PDF 與本機 PDF、文字、CSV、JSON 上傳；6 MB 上限。PDF 最多 150 頁、文字最多保留 120,000 字元；AI 每次處理前 18,000 字元，明示截斷，不宣稱讀完全部文件。CSV 目前當文字抽取，不是完整資料表分析器。
- **草稿確認**：保留原文摘錄、PDF 頁碼或模型定位、檔案 SHA-256 與處理範圍。摘錄必須在處理的原文找到，才可進入核對表單。資料類型與未知尺度需人工選擇，不會把模型輸出自動標成 REAL。確認前不參與分析；quoteFound 也不代表數字、分母或來源品質已驗證。
- **AI 問題探索**：模型自由產生候選，沒有固定問題類型限制。Evidence ID 需存在於實際輸入。引用與結構檢查通過不代表證據實際支持模型內容；仍需人工審查問題重要性、語意與因果宣稱。資料變更後的舊 AI 輸出保留，但不再套用。
- **成因與反證**：保留候選、替代解釋與資料缺口；可提交異議並重新調查。對前兩項模型假說自動查詢支持與反向文獻線索；需讀全文與人工核對後，才可列為證據。查不到不能解讀為沒有反證。
- **方案**：依模型提出的假說連結；無效方案會隔離並保留原因。模型不填入成本、效果係數與覆蓋率假數字。一般 AI 問題尚未定義結果指標與計算模型，因此不套用舊旅行時間或上網率公式。原有案例規則的 L1 仍可操作；L2 回測與 L3 因果效果評估尚未實作。
- **評分**：新問題品質與 Benchmark 都用 0–4，須理由與評估者。舊版 0–5 紀錄顯示原尺度，不自動換算；重新評分前的紀錄存入歷史。人工分數不是 AI 正確率。
- **報告與重現**：保存模型輸入、提示、輸出、參數、耗時、失敗、來源及限制。凍結輸出可以檢視與分享，但相同 seed 不保證模型重跑逐字相同。

## 正式 A／B／C

研究評估頁可依序呼叫同一個本機模型三次。A 僅指定尺度，B/C 使用相同完整資料；三組共享任務、token 上限、temperature 與 seed，方法指令依研究設計不同。輸出、輸入與失敗逐組保存，模型不自動評分。需事先固定案例參考答案，完成多案例、多次測試及獨立評分，再檢查 QG4。不能因 C 提示較完整、找到更多候選或某一次輸出較長，就宣稱方法較好。

## 本次驗證與尚未完成

2026-11-26 在這台 Windows 電腦實跑：Ollama `qwen3:0.6b` 約 64 秒產生一項引用可回查的候選，主要描述資料缺口，**不是經研究驗證的新問題**；較早一次輸出有無效方案連結，已保留並測試隔離，`phi3` 一次超時也保留。小模型的語意與推理能力有限，正式研究應測量品質，不把可連線當作分析可靠。

已測試：原始計畫書 PDF 文字讀取（7,859 字元）、實際 Crossref 搜尋、合成文字的真實模型抽取（100→80，原文摘錄可比對）、真實模型結果在 UI 的顯示、成因、數值阻擋、報告匯出、儲存、資料變更失效、五工作區與手機版，以及 v0.2 的完整回歸測試。這些是軟體與管線測試，不是政策成效或方法優越性研究。

尚未完成：完整台灣政府資料自動搜尋、多來源真實地理尺度整合、長文件自動分批讀完、正式多案例獨立評分、L2/L3 效果研究。測試輸出不會預載到公開網站。
